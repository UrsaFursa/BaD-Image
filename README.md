# BaD-Image
BaD-image is used to check backdoors on images from unknown sources to avoid virus insertion on the device. easy to use and very light.

## requirements
"""
- torch
- torchvision
- matplotlib
- numpy
- scikit-learn
- opencv-python

## Usage
1. Install dependencies:
   pip install -r requirements.txt

2. Run detection:
   python main.py
